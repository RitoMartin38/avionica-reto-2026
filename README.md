# Sistema de recuperación - Aviónica AAIAQ

## Información del proyecto

- **Proyecto:** Reto de reclutamiento AAIAQ
- **División:** Aviónica
- **Ruta:** 3 - Firmware y sistemas embebidos
- **Enfoque:** Sistemas de control
- **Lenguaje:** C/C++

## Objetivo

Desarrollar un sistema de control basado en una máquina de estados finitos para simular la lógica de recuperación de un vehículo aeroespacial.

## Funcionalidades

- Máquina de cinco estados.
- Detección de pulsaciones cortas y largas.
- Antirrebote por software.
- Temporizadores no bloqueantes.
- Indicadores LED.
- Registro de eventos por comunicación serial.
